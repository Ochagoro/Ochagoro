01 — 拠点

Buck Meadows は、
「早く着ける」宿である。

Yosemite Westgate Lodge（7633 State Hwy 120）は Big Oak Flat 入口ゲートまで約12マイル・20分。園内の宿より安く、園外の他の宿より圧倒的に近い。この20分は、夏のヨセミテでは「駐車場を確保できるかどうか」とほぼ同義です。ロッジ併設の Lucky Buck Cafe は7:00開店なので、朝食は前夜に買っておくのが正解。

8月の滝は、期待しない

ヨセミテ滝は8月にはほぼ枯れます（雪解けが終わるため）。年間で水が流れ続けるのは Bridalveil・Vernal・Nevada の3つだけ、それも細め。「滝を見に行く月」ではなく「岩と光と川を楽しむ月」と割り切ると、満足度が跳ね上がります。

渓谷は暑い、高地は快適

渓谷（標高1,200m）は午後に32〜36℃まで上がります。一方 Glacier Point（2,199m）や Tioga Rd 沿い（2,500m前後）は日中24℃前後、夜は10℃台前半。正午前後を渓谷で過ごす計画は失敗します。暑い時間は川か木陰、涼しい時間に歩く。

2026年は入園予約が不要

ピーク時間帯の事前予約制は2026年で廃止。予約なしでいつでも入れます。ただし混雑そのものは残るので、実質的な制限は「駐車場の空き」。渓谷の駐車場は夏の週末なら9〜10時で満車になります。

園内はほぼ圏外

渓谷の一部（Yosemite Village 周辺）を除き、携帯はほぼ繋がりません。地図・このページ・音楽は前夜にロッジのWi-Fiでダウンロード。同行者とは「はぐれたら◯時に◯◯」を先に決めておくのが鉄則です。

02 — 高低差

1日で 1,500m 登って、降りる。

この日の主役は距離ではなく標高です。930mの宿を出て、渓谷底1,200m、滝の上1,537m、そして夕方に一気に2,476m。上に行くほど気温は下がり、紫外線は強くなり、空気は薄くなります。上着と水は「高さのための装備」だと思ってください。

03 — 本命プラン

渓谷の朝、川の昼、
断崖の日没。

西ゲート泊の強みを全部使う組み立て。「朝いちばんに人のいない渓谷を取り、暑い時間は川で潰し、夕方に標高を上げて日没を取る」。これが8月のヨセミテで一番おいしい順番です。

04:45起床 · 外は真っ暗

顔を洗って、車に乗る。

朝食は前夜に買ったものを車内で。Lucky Buck Cafe は7:00開店なので待っていると1日が崩れます。荷物は前夜に積み終えておく。

05:10ロッジ発

Hwy 120 を東へ

ヘッドライトの中を走る20分。この時間帯は鹿が本当に出るので、制限速度＋αは厳禁です。途中の Rim of the World 展望台（トイレあり）は、余裕があれば5分だけ。トゥオルミ川の峡谷が夜明け前の青に沈んでいます。

19 km約20分給油は前夜にGrovelandで

05:45Big Oak Flat 入口ゲート

ゲート待ちゼロで入園

$35／台、7日間有効。America the Beautiful パス（$80）があればそれで。この時間なら列はありません。9時に来ると同じゲートで20〜40分並びます。ここが西ゲート泊の最大の投資回収ポイント。

$35 / vehicleカード可標高 約1,490m

06:35Valley View · 15分

マーセド川の水鏡に、エル・キャピタン

El Portal Rd 沿いの小さな路肩。8月は水位が下がって流れが止まり、むしろ鏡のように映り込みます。朝の斜光が谷の奥から差してくる15分間、ここにいる人は数人。渓谷で最初に見るべき場所です。

Note駐車スペースは10台ほど。西向き（下り）車線側にあるので、通り過ぎたら次のターンアウトでUターン。

07:00Tunnel View · 20分

この1枚のために、早起きした

エル・キャピタン、ブライダルベール滝、ハーフドームが一望に収まる、ヨセミテでもっとも有名な視点。8時を過ぎると駐車場は満車で路肩待ちの列ができます。7時ならまだ空いています。朝は逆光気味なので、露出を少し下げて撮ると谷の奥行きが出ます。

Wawona Rd (Hwy 41)トイレあり渓谷から車で10分の登り

07:35Bridalveil Fall · 30分

8月でも落ちている、数少ない滝

駐車場から往復800m、舗装された緩い坂。夏は「花嫁のベール」の名の通り細く、風で横に流されます。朝いちなら展望デッキを独占できます。足元の岩は年中濡れていて滑るので、展望台から先には出ないこと。

08:20Yosemite Village · 車をここに置く

今日、車を動かすのはこれが最後

渓谷に入ったら Yosemite Village か Curry Village の駐車場に停め、あとは無料シャトルと自分の足だけで動きます。渓谷内を車で移動するのは時間の無駄（渋滞と駐車場探しで1回30分は溶ける）。8時台なら確実に停められます。

無料シャトル 夏季 朝〜夜レンタサイクルもあり給水所あり
ここで補給Village Store で昼のサンドイッチと行動食、ボトルに給水。園内で食べ物を買えるのはほぼここだけで、昼は行列します。

09:00Mist Trail · 2〜3時間

今日いちばんの運動：Vernal Fall

シャトルで Happy Isles へ。ここから2つの選択肢：

A｜Footbridge まで 2.6 km ↑120m 約1.5時間
B｜Vernal Fall 上まで 3.9 km ↑300m 約3時間

Bは花崗岩の階段を600段以上登ります。8月は水量が少ないので、春のようにずぶ濡れにはなりません——その代わり日陰が少なく暑い。10時までに登り始めること。水は1人1.5L以上を必ず持って。

体力を残したいならMist Trail をやめて Cook's Meadow Loop（1.6km・完全平坦）へ。草地の真ん中からハーフドームとヨセミテ滝の岩壁を見上げる、渓谷でいちばん贅沢な散歩道です。夕方の Glacier Point に体力を回せます。

12:30昼食 · 川辺

Swinging Bridge の河原でピクニック

買っておいたサンドイッチを、マーセド川の砂地で。レストランに並ぶ時間がもったいないし、この時期の川辺のほうが確実に気持ちいい。食べ終わったゴミは絶対に置いていかない（熊とカラスが来ます）。

13:00灼熱の2時間 · 川

暑い時間は、歩かずに泳ぐ

渓谷は午後に35℃近くまで上がります。ここで無理に歩くと、夕方のいちばんいい時間に電池が切れる。Sentinel Beach か Swinging Bridge で川に入ってください。8月のマーセド川は流れが穏やかで水温も高く、1年でいちばん泳ぎやすい時期です。

そして双眼鏡でエル・キャピタンを見上げること。900mの壁のどこかに必ずクライマーが数パーティ張り付いています。壁で寝るポータレッジが見つかったら、その日は当たりです。

水着 + 速乾タオル川用サンダル（石が滑る）日陰にタープ代わりの上着

15:00涼む / 予備時間

Ansel Adams Gallery とビジターセンター

体を冷やしつつ、今日見てきた岩がどうやってできたのかを回収する時間。ここは天候や疲労に応じて削っていい枠です。15:30には必ず車に戻ります。

16:45Glacier Point · 標高 2,199m

ハーフドームと、同じ高さに立つ

渓谷から Wawona Rd → Glacier Point Rd で約1時間。駐車場から100m、舗装路を歩くだけで断崖の縁に出ます。足元1,000m下にさっきまでいた渓谷、正面にハーフドームの丸い背中。ヨセミテで「労力あたりの絶景」が最大の場所です。ここで上着を出してください。すでに空気が違います。

2,199 mバリアフリートイレ・売店あり夕方は 12〜16℃

17:15Sentinel Dome または Taft Point · 各1.5時間

日没まで、もうひと歩き

Sentinel Dome（往復3.5km・↑120m・2,476m）は、この日の最高地点。丸い花崗岩のドームの上に立つと360度、ハーフドームからシエラの奥まで遮るものがありません。Taft Point（往復3.5km・ほぼ平坦）は、岩盤に走る深い裂け目と柵のない絶壁。高所が平気な人にはこちらのほうが刺さります。

安全Taft Point には手すりがほとんどありません。縁から2m以上離れる、写真に夢中で後ずさりしない、子どもからは手を離さない。毎年ここで事故が起きています。
トレイル入口は Glacier Point Rd 沿いヘッドランプ必携

19:45日没 20:05 · 今日の頂点

ハーフドームが、ピンクに焼ける

日が落ちる直前の10分、花崗岩が赤みを帯びた光を反射して、谷全体が桃色に染まります。本番は「日没の瞬間」ではなく、その後の15分です。太陽が消えてから空の色が抜けるまで、粘れるだけ粘ってください。気温は一気に落ちるのでフリース＋ウインドシェル。

Sunset 20:05薄明終了 20:35三脚があると化ける

20:35下山開始 · 約2時間10分

夜のシエラを、ゆっくり降りる

Glacier Point Rd → Wawona Rd → Big Oak Flat Rd → Hwy 120。この帰り道が、このプラン唯一の代償です。鹿・熊・カーブ・下り勾配。制限速度を守って、眠かったらターンアウトで停まる。運転を交代できるなら必ず交代を。

途中で1回だけ寄るならGlacier Point Rd の路肩か Washburn Point。8月のヨセミテは月が出ていなければ天の川が肉眼でくっきり見えます。エンジンを切って5分、目を暗闇に慣らしてから空を見上げてください。

22:45ロッジ帰着

17時間。

Lucky Buck Cafe は21:00で閉まっているので、夕食は昼のうちに買っておいた分で。車内に食べ物を残さないこと——駐車場でも熊は来ます。

もう1時間早く寝たいならGlacier Point をあきらめ、Tunnel View で日没に切り替える。ロッジまで約1時間20分に短縮できて、21:30には戻れます。絶景の格は落ちますが、夜道の運転は半分です。

04 — 別プラン

渓谷に行かない、
という選択肢もある。

West Gate Lodge から Crane Flat（Tioga Rd の入口）まではわずか35分。実は渓谷より近い。混雑と暑さが苦手なら、こちらのほうが体験の密度は高いかもしれません。

標高2,600mの、もうひとつのヨセミテ

渓谷の10分の1の人出／気温は10℃低い／8月は泳げる

  • 06:00ロッジ発 → Crane Flat約35分・園内で最も近い入口エリア
  • 06:45Tuolumne Grove of Giant Sequoias／往復4km、下り500m・帰りは登り。ジャイアントセコイア約20本と、幹を歩いて抜けられる Tunnel Tree。朝いちなら森を独り占めできる／約1.5〜2時間
  • 09:30Tioga Rd を東へ。標高がぐんぐん上がるWhite Wolf、Siesta Lake などの路肩を拾いながら
  • 10:15Olmsted Point／2,569m。ハーフドームを裏側から見る唯一の場所。氷河が磨いた岩盤と、置き去りにされた迷子石。駐車場から数分
  • 11:15Tenaya Lake／2,484m。白い花崗岩の砂浜と青い水。8月はヨセミテで泳ぐのに最高のタイミング。水着・タオル必須／2〜3時間滞在してよい
  • 14:00Tuolumne Meadows／2,627m。シエラ最大級の高山草原。Soda Springs 往復3km（平坦）か、Lembert Dome へ。午後の光が草原に入るのがきれい
  • 16:30Tioga Pass／3,031m まで往復。カリフォルニアで車で行ける最高所のひとつ。ゲートの外に出ると再入園扱いになる点だけ注意
  • 18:30折り返し、Olmsted Point で夕日逆光のハーフドームがシルエットになる
  • 20:40ロッジ帰着Tuolumne Meadows からロッジまで約2時間

向いているのは：ヨセミテが2回目以上の人／人混みが本気で苦手な人／泳ぎたい人／写真を撮る人。
注意：2,600m は高山病の入り口です。頭痛・だるさが出たら下ります。水を多めに、動きはゆっくり。日焼けは渓谷の比ではありません。

06 — 前夜

この6つを寝る前に。

4:45起きの朝に判断を残さないこと。前夜の30分が、翌日の2時間になります。

Groveland で満タン給油

園内のガソリンスタンドは Crane Flat と Wawona だけ、しかも割高。Groveland のスタンドで入れておく。1日の走行は約210kmです。

明日の食料と水を買う

朝食・昼食・行動食・水。ロッジ周辺か Groveland のストアで。園内で買うと高いうえ、時間を行列で失います。

オフライン地図をダウンロード

ロッジのWi-Fiで、Googleマップの「ヨセミテ周辺」をオフライン保存。NPSアプリの Yosemite もダウンロード。このページもブックマークを。

Lucky Buck Cafe で夕食

ロッジ併設（7647 State Hwy 120）、21:00まで。翌日は22時過ぎに帰るので、まともな夕食はここが最後です。

車から食べ物を全部出す

Buck Meadows の駐車場にも熊は来ます。食料・お菓子・リップクリーム・日焼け止めまで、匂いのあるものは部屋へ。

荷造りを終えて、4:45にアラーム

朝は「顔を洗って車に乗る」だけの状態にしておく。上のチェックリストを埋め切ってから寝てください。

07 — 現地の掟

守らないと、
高くつく4つ。

Bears

車内に食べ物を「見える形で」置かない

ヨセミテのクマは車をこじ開けます。トレイルヘッドには食料ロッカーがあるので必ずそれを使う。対象は食べ物だけでなく、匂いのあるもの全般（リップ、日焼け止め、空の容器、ゴミ）。違反には罰金があります。

No Signal

圏外を前提に動く

渓谷の一部を除き携帯は繋がりません。地図はオフライン保存、集合場所と時刻は先に口頭で決める。緊急時は最寄りのビジターセンターかレンジャーへ。スマホは機内モードにしておくと電池が持ちます。

Parking

停めたら、夜まで動かさない

渓谷の駐車場は夏の日中に満車になります。一度出ると戻れないと思ってください。移動は無料シャトルとレンタサイクルで。園内の制限速度（25〜45mph）は厳格に取り締まられています。

Heat

正午の渓谷を歩かない

8月の渓谷は35℃前後。この日いちばんのリスクは滑落でも熊でもなく熱中症です。11〜15時は川か木陰か屋内。水は「喉が渇く前に」飲む。頭痛・吐き気が出たら即座に日陰へ。
